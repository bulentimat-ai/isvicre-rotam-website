# İsviçre Rotam — Web Sitesi

İsviçre Rotam iOS uygulamasının herkese açık destek ve gizlilik sitesi (statik HTML/CSS, GitHub Pages).

## Özel alan adı (taslak — henüz canlıya alınmadı)

- Hedef ana sayfa: https://isvicrerotam.com/
- Hedef gizlilik: https://isvicrerotam.com/gizlilik/
- Hedef destek: https://isvicrerotam.com/destek/
- Hedef hakkında: https://isvicrerotam.com/hakkinda/
- GitHub Pages: `Settings → Pages → Custom domain` alanına `isvicrerotam.com` yazılmalı.
- DNS: `@` için GitHub Pages A kayıtları; `www` için `bulentimat-ai.github.io` CNAME.
- Alan adı ve TLS/DNS doğrulanana kadar mevcut GitHub Pages adresi App Store Connect içinde değiştirilmemeli.

## Kurumsal e-posta adresleri

- Teknik destek: destek@isvicrerotam.com
- Genel bilgi ve gizlilik talepleri: info@isvicrerotam.com
- E-posta kutularının ve MX/SPF/DKIM/DMARC kayıtlarının alan adının e-posta sağlayıcısında ayrıca yapılandırılması gerekir.

Bu depo yalnızca web sitesini içerir; uygulama kaynak kodu burada değildir.
Site çerez, analitik, reklam veya harici komut dosyası kullanmaz.

Yayın: GitHub Pages → `main` dalı, kök dizin (`/`).
